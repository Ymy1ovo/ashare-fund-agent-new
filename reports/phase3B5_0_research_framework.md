## 1. 基金产品类型分类体系

### 1.1 九类产品

| 类 | 名称 | 默认研究池 | 识别依据 | 比较规则 |
| --- | --- | --- | --- | --- |
| `ordinary_index` | 普通开放式指数基金 | ✅ | is_index_fund | 宽基与行业主题必须分开比较；不同跟踪指数不得混排 |
| `etf_linked` | ETF 联接基金 | ✅ | fund_name 含「ETF联接」 | 与直接指数基金可比，但需注明是否含 ETF 折溢价传导 |
| `active_equity` | 主动权益基金 | ✅ | fund_type_l1 in (股票型, 混合型-偏股) | 必须按可验证的业绩基准分组，不得与指数基金混排 |
| `bond_pure` | 普通债券基金 | ✅ | fund_type_l1 含「债券型」 | 按久期分组；久期字段缺失则标 unknown |
| `bond_mixed` | 混合债券基金 | ✅ | fund_type_l1 含「债券型」+ 含权特征 | 不得与纯债混排；转债暴露未知时标 unknown |
| `money_market` | 货币基金 | ✅ | fund_type_l1 含「货币型」 | 独立收益口径（每万份收益/7日年化），**不得**与净值型基金计算同类收益/回撤 |
| `qdii` | QDII 基金 | ❌ | fund_type_l1 含 QDII | 样本为 0，本轮不纳入研究池 |
| `lof` | LOF 基金 | ✅ | fund_name 含 (LOF) | 按底层是主动还是指数再分组 |
| `onshore_etf` | 场内 ETF | ❌ | product_structure='etf' | **禁止**混入场外默认研究池 |

### 1.2 场外 vs 场内隔离

| 项 | 内容 |
| --- | --- |
| 默认研究池 | 场外（ordinary_open_ended / etf_linked / lof） |
| 排除 | `onshore_etf` |
| 场内 ETF 代码 | `511000`、`511050` |

> 场内 ETF 仅保留历史研究，**不得**混入场外默认研究池；两者费用、交易机制、申赎方式完全不同

### 1.3 本体与份额规则

| 项 | 规则 |
| --- | --- |
| 基础原则 | A/C/E 是同一基金本体的不同份额，共享同一投资组合 |
| 比较策略表现时 | 比较策略表现时先按 fund_id 归并到基金本体（用主份额净值代表组合表现） |
| 比较持有成本时 | 比较持有成本时再按份额单独比较（销售服务费、申购费差异） |
| 主份额 | 每个本体恰好一个 is_primary=1 主份额（3B-4.2 已验收） |

**禁止归并**：

- ❌ 不同 fund_id 的基金不得归并
- ❌ 货币基金份额不得与净值型份额归并

### 2.3 逐项主要风险

**单位净值**

- 无真实净值公布日历，连续性 cannot_verify
- 只反映单只基金自身序列，跨基金日期不可强制对齐
- 不能确认某交易日缺净值就是数据缺失

**累计净值**

- 与单位净值口径不同（含分红再投资假设），禁止混用
- 分红完整性未验证，累计净值中隐含的分红部分无法独立核对

**货币基金每万份收益**

- **与净值型基金口径完全不同**，不得参与净值收益/回撤计算
- 单位是「元/万份」，不是收益率

**7日年化收益率**

- 是年化换算后的**参考值**，不是已实现收益
- 不得与净值型基金的年化收益直接比较

**分红**

- 接口单次返回不完整（3B-3.1 实测同基金不同请求结果不同）
- 3B-4.4 跨来源核验：44 条中 35 条匹配公告、4 条公告在 DB 缺失
- **禁止用于修正历史收益**

**管理费**

- 年化费率从净值中已扣除，**不得在成本模拟里重复计提**
- 79 条无生效日，不能还原历史费率
- 生效日之前必须用 detail.rate_before

**托管费**

- 同上：已在净值中扣除
- 与申购赎回费性质不同，不能混算为「交易成本」

**销售服务费**

- 110022 该字段页面为 ---，存 NULL 不当 0
- C 类份额特有，A 类通常为 0
- 已在净值中扣除，不得重复计提

**申购费**

- 平台优惠费率是天天基金，**不代表支付宝**
- 阶梯金额边界含推断下界（lower_inferred=1）
- 不能还原历史申购费率

**赎回费**

- 持有期按自然日还是交易日**未确认**（holding_days_basis 全 NULL）
- 区间开闭部分未知，档位可能差一档
- 不能还原历史赎回费率

**基金规模**

- 日期语义是 platform_observation_date，报告期末**未核实**
- 138 个日期中 54 个不是季末
- disclosed_at 全 NULL，公开可见时间 unknown
- **禁止作为历史时点因子/回测已知信息**（未来信息泄漏）

**基金经理任职历史**

- 部分记录仍是快照（无任职日期）
- 不能回填历史，不能用当前经理名单反推过去
- 无「某时点在任经理完整名单」的序列

**基金成立日期**

- 41 个清盘本体成立日期全 NULL
- 成立日期可用于过滤「成立不足 N 年」，但不得推断业绩

**基金终止/清盘事件**

- 清盘名录覆盖率 **not_quantifiable**，不是全量名录
- 幸存者偏差 **未消除**
- 12 条缺 event_date（只有公告日期）
- 可用于剔除已知清盘，**不得**声称覆盖完整

**支付宝可购买状态**

- 支付宝无公开合法接口，禁止逆向 APP / 绕过登录
- 天天基金「开放申购」**不代表**支付宝可买
- **unknown 不等于 false**，不得当作「不可购买」
- 转人工核验，核验结果需带 verified_at，90 天过期

### 2.4 准入原则

- unknown 不等于 false，NULL 不等于 0
- 接口能返回不等于证据等级高
- 已在净值中扣除的费率不得重复计提
- 平台日期不等于报告期末，报告期末不等于投资者已知
- 已知清盘清单不等于全量清盘名录

### 2.5 证据等级定义

| 等级 | 定义 |
| --- | --- |
| **A** | 官方原始来源，可追溯原始公告或正式文件 |
| **A-** | 基金管理人正式公告原文，经第三方公告库转发，公告 ID 可回源 |
| **B** | 可信第三方转载或整理，但未逐条回源官方原文 |
| **C** | 第三方数据平台信息，尚未与合同或官方数据逐条核验 |
| **D** | 推断、代理或人工假设 |
| **unknown** | 无法确认 |

## 3. 研究指标设计

### 3.1 收益指标

| 指标 | 窗口 | 依赖 | 风险 |
| --- | --- | --- | --- |
| 近 1 月收益 | 21 交易日 | unit_nav 或 acc_nav | 短期噪声大，禁止单独用于排序 |
| 近 3 月收益 | 63 交易日 | unit_nav 或 acc_nav | 同上 |
| 近 6 月收益 | 126 交易日 | unit_nav 或 acc_nav | 同上 |
| 近 1 年收益 | 252 交易日 | unit_nav 或 acc_nav | 单年受市场风格影响大 |
| 近 3 年收益 | 756 交易日 | unit_nav 或 acc_nav | 需至少 3 年数据；不足则 excluded 不插值 |
| 成立以来收益 | 成立日至最新 | established_date, unit_nav/acc_nav | 41 个清盘本体无成立日期；不同基金区间不可直接比 |
| 年化收益 | (1+累计收益)^(1/年数)-1 | 足够长区间 | 短区间年化会放大极端值，样本<1年禁止输出 |
| 滚动收益分布 | 滚动 N 日（如 252 日） | 连续净值序列 | 净值连续性 cannot_verify，滚动窗口可能跨越缺失期 |

### 3.2 风险指标

| 指标 | 公式 | 依赖 | 风险 |
| --- | --- | --- | --- |
| 最大回撤 | `max(1 - NAV_t / max(NAV_0..t))` | 净值序列 | 依赖净值连续性；缺失期会低估回撤 |
| 年化波动率 | `std(日收益) × sqrt(252)` | 日收益序列 | 252 是假设值；基金实际公布频率不同 |
| 下行波动率 | `std(min(日收益, 0)) × sqrt(252)` | 日收益序列 | 同上 |
| Sharpe | `(年化收益 - 无风险利率) / 年化波动率` | 年化收益, 年化波动率, 无风险利率 | 无风险利率来源未定；本项目暂无可靠无风险利率序列 |
| Sortino | `(年化收益 - 无风险利率) / 下行波动率` | 同上 + 下行波动率 | 同上 |
| Calmar | `年化收益 / 最大回撤` | 年化收益, 最大回撤 | 最大回撤为 0 时无定义 |
| 回撤修复时间 | `从最低点回到前高所需交易日` | 净值序列 | 未修复则标记「至今未修复」，不填 0 |

### 3.3 稳定性指标

| 指标 | 公式 | 依赖 | 风险 |
| --- | --- | --- | --- |
| 滚动窗口正收益比例 | 滚动 N 日中收益>0 的占比 | 净值序列 | 窗口长度选择影响结果，必须标注 |
| 不同市场阶段表现 | 按预设市场阶段切分（牛/熊/震荡） | 市场阶段划分依据 | **阶段划分本身是人为选择**，必须有明确规则并披露 |
| 收益集中度 | Top-N 月份收益占总收益比例 | 月度收益 | 总收益为负时该指标无意义，需标注 |
| 极端月份贡献 | 最大单月正/负收益 | 月度收益 | 单月数据可能受分红/拆分影响 |
| 与基准偏离 | 基金收益 - 基准收益 | benchmark 字段, 基准收益序列 | **基准收益序列本项目尚未采集**；benchmark 文本也需解析 |

### 3.4 主动权益专项

| 指标 | 状态 | 阻塞项 |
| --- | --- | --- |
| 相对基准超额收益 | **blocked** | 基准收益序列未采集，benchmark 为自由文本 |
| 经理任职区间表现 | **partial** | 仅 12 条有日期，其余为快照 |
| 风格稳定性 | **blocked** | 本项目未采集持仓数据 |
| 规模变化 | **descriptive_only** | 日期是平台观测日期，不是验证报告期末 |

### 3.5 明令禁止的处理方式

- ❌ 把基金经理快照当历史时点特征
- ❌ 把规模平台观测日期当报告期末或时点已知信息
- ❌ 用不完整分红修正历史收益
- ❌ 把当前费率倒填历史区间
- ❌ 把支付宝 unknown 当作可买或不可买
- ❌ 把 41 条清盘记录说成全量名录
- ❌ 用单一短期收益排序选基

## 4. 基金比较规则

| 分组 | 规则 | 理由 |
| --- | --- | --- |
| 指数基金 | 宽基指数与行业主题指数**必须分开** | 波动率与收益分布差异极大，混排会得出错误结论 |
| 主动权益 | 必须按可验证的业绩基准分组 | 无基准则无法判断是能力还是风格暴露 |
| 债券基金 | 按久期、信用风险、转债暴露分层 | 这些字段当前**多数缺失**，缺失标 unknown 不猜 |
| 货币基金 | 独立收益与风险口径 | 每万份收益/7日年化与净值型不可比 |
| A/C 份额 | 先按 fund_id 归并比较策略表现，再单独比较份额成本 | 同一组合、只有费率差 |
| 成立时间 | 成立不足 N 年不得与完整周期基金直接比较 | 样本长度不同，统计量不可比 |

> 没有可靠分类字段时标记 `unknown`，**不猜测、不按名称臆断**

| `consequence` | 清盘本体无法用库字段分类，只能依赖 3B-4.1.1 校准 JSON；研究池若纳入清盘样本，必须显式声明分类来源 |

## 5. 研究性排名设计原则

### 5.1 状态

| 项 | 值 |
| --- | --- |
| 状态 | **design_only** |
| 生成真实排名 | **False** |
| 生成交易信号 | **False** |

### 5.2 八条原则

1. 不使用未来数据（所有指标只用截至 t 日已公布的数据）
2. 不用单一短期收益排序
3. 先做同类比较，跨类不排名
4. 风险指标必须参与，不能只看收益
5. 样本长度和数据质量必须参与评分
6. 历史收益高不等于推荐
7. 缺失数据降级或排除，不静默填补
8. 所有评分项可追溯到来源与计算过程

### 5.3 五维评分

| 维度 | 权重 | 组成 | 设计依据 |
| --- | ---: | --- | --- |
| **收益** | 30% | ret_1y, ret_3y, annualized_return | 中长期收益为主，1 月/3 月只作参考不进主分 |
| **风险** | 30% | max_drawdown, annualized_vol, downside_vol | 风险与收益同权重，防止纯收益排序 |
| **风险调整收益** | 20% | sharpe, sortino, calmar | 单位风险回报，需无风险利率（当前缺失→降级） |
| **稳定性** | 15% | positive_ratio, return_concentration | 防止靠单月暴涨刷高收益 |
| **数据质量** | 5% | 样本长度, 缺失率, 证据等级 | 数据差的基金即使指标好看也要降权 |

**权重依据**：收益与风险等权（各 30%）体现「不唯收益」；风险调整收益 20% 是收益/风险的二次确认；稳定性 15% 抑制极端值；数据质量 5% 是门槛而非主导，避免数据好的基金被过度加分

### 5.4 缺失值处理

- 关键指标缺失（如净值序列不足）→ 该基金**排除出排名**，不补零
- 非关键指标缺失（如 Sharpe 缺无风险利率）→ 该维度降权并标注
- 数据质量分低于阈值 → 整只基金标 C 档，仅供观察
- 任何插值必须在输出中显式标注方法与影响

### 5.5 适用条件 / 禁止场景

| 适用 | 禁止 |
| --- | --- |

| 同一产品类别内比较 | 跨产品类别排名（指数 vs 主动 vs 债券 vs 货币） |
| 样本期长度相近 | 样本期差异过大（1 年 vs 10 年） |
| 数据完整性达到 B 档以上 | 把规模/经理快照当因子 |
|  | 把该评分当作买入建议 |

## 6. 研究池准入等级

> 同一基金的不同**数据字段**可以有不同等级，**不得**给整只基金打一个笼统可信度标签

| 档 | 名称 | 含义 |
| --- | --- | --- |
| **A** | 可直接用于研究 | 数据来源明确、覆盖完整、口径已确认 |
| **B** | 有条件用于研究 | 数据可用但存在已知限制，使用必须带条件 |
| **C** | 仅辅助观察 | 存在明显完整性或语义缺陷，不能支撑结论 |
| **D** | 禁止用于相应研究用途 | 数据本身不可靠或语义不成立，任何正式使用都禁止 |

### 6.1 当前各档实例

**A 档 —— 可直接用于研究**

- 历史单位净值（单序列描述性分析）
- 已知清盘事件清单（用于剔除，不声称完整）

**B 档 —— 有条件用于研究**

- 累计净值（需明确与单位净值不混用）
- 11 条有公告生效日的年化费率（仅生效日后）
- 有公告任职日期的 12 条经理记录（仅已知区间）
- 基金成立日期（仅用于过滤，不推断业绩）

**C 档 —— 仅辅助观察**

- 基金规模历史（平台观测日期，非验证报告期末）
- 分红记录（完整性未验证）
- 无生效日的 79 条费率
- 无任职日期的经理快照

**D 档 —— 禁止用于相应研究用途**

- 支付宝可购买状态（unknown）
- 支付宝实际费率（无数据源）
- 规模记录作为历史时点因子/回测已知信息
- 把 41 条清盘记录当全量名录
- 净值连续性结论（cannot_verify）

### 6.2 同一基金不同字段等级示例

> 同一基金不同字段等级不同：**110022 易方达消费行业股票**

| `alipay` | D（unknown） |
