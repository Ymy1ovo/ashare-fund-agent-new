## 4. 全收益与价格指数的数值关系

### 4.1 跨年份样本（以 `H00300` / `000300` 为例）

| 日期 | 价格指数 | 全收益 | 比值 |
| --- | ---: | ---: | ---: |

| 2005-01-04 | 982.79 | 982.79 | **1.000000** |

| 2007-01-04 | 2,067.09 | 2,106.44 | 1.019036 |
| 2008-01-02 | 5,385.10 | 5,523.94 | 1.025782 |
| 2024-01-02 | 3,386.35 | 4,709.92 | 1.390854 |
| 2025-01-02 | 3,820.40 | 5,478.38 | 1.433981 |
| 2026-01-05 | 4,717.75 | 6,956.12 | 1.474457 |

### 4.2 重要发现：早期比值恰为 1

**`H00300` 有 175 个交易日的比值恰为 `1.000000`**（`H20539` 有 78 个）。

这说明：**该段全收益序列与价格指数完全相同，未体现分红再投资。**

可能原因（均为**推测，未证实**）：
- 早期官方未计算分红再投资；
- 或早期样本分红极少。

**这必须在使用时注意：不能假定全收益序列在全区间都含分红再投资。**

### 4.3 判据修正记录

**初版判据「比值恒 ≥ 1」是错误的**：

- 全收益与价格指数**同基点**（1000），基日当天比值必然 **= 1**；
- 若用「> 1」，会把 `H00300`、`H20539` 等正确序列误判为映射失败。

修正为「比值恒 **≥** 1」，并单独记录等于 1 的日期数。

### 4.4 映射结论的强度声明

| 判据 | 强度 | 能否单独证明映射 |
| --- | --- | --- |
| 名称含「全收益/净收益」 | 弱 | ❌ |
| 基日一致 | 中 | ❌ |
| 比值恒 ≥1 且上升 | 中 | ❌ |
| **三者同时成立** | 中强 | **仍是技术判断** |

**所有映射结论均为技术判断，不能替代官方口径文件。**

## 5. 债券与港股的特殊处理

### 5.1 债券衍生序列（`H00012` / `N00012`）

| 项 | 结果 |
| --- | --- |
| 官方身份 | ✅ 上证国债指数(净价) / (利息及再投资) |
| 收益口径 | **❌ 不适用股票全收益口径** |
| 映射 | ❌ 基日不一致，比值不上升（1.008 → 0.473） |
| 历史接口 | ✅ 3,376 行 |
| 覆盖/质量/连续 | ✅ |

**结论：债券衍生序列必须独立研究，不得混入股票全收益统计。**
比值从 1.008 降到 0.473，符合「净价指数不含应计利息累积」的特征，
但这与股票全收益的「比值上升」特征完全相反，**不能套用同一判据**。
