# 阶段3B-6.2.2 设计：支付宝场外公募基金与基准映射规则

- 基线 HEAD：`e9fcd3cd197c7f58d3267d3a20825caa6e320548`
- 映射规则版本：`3B-6.2.2-v1`

> **本阶段只做映射规则建设与只读审计。不接入基准收益序列，不开放回测。**

---

## 1. 设计目标

在 3B-6.2.1 分类体系之上，建立**确定性、可解释、可追溯**的基金—基准映射规则。

| 要求 | 实现 |
| --- | --- |
| 确定性 | 同样输入必得同样输出（纯函数，无随机、无时间依赖） |
| 可解释 | 每条映射都输出 `reasons` / `unavailable_reason` |
| 可追溯 | 每条记录带 `mapping_rule_version` + `category_rule_id` |
| 三类隔离 | `contract` / `research` / `substitute` 独立记录 |

---

## 2. 三类基准的映射结构

每只基金输出**三条互相独立的记录**：

| 字段 | contract | research | substitute |
| --- | --- | --- | --- |
| `kind` | `contract` | `research` | `substitute` |
| `available` | 需 L1 + 全成分 + 历史权重 | 需口径确认 + 规则声明 | 需调用方显式选择 |
| `candidate` | — | 有指数点位即候选 | 有任一系列即候选 |
| `evidence_grade` | 实际证据等级 | 刻意标 `L3` | 刻意标 `L3` |
| `unavailable_reason` | 必须给出 | 必须给出 | 必须给出 |

**三条记录绝不互相赋值**，也不存在 `contract = research` 这类捷径。

## 4. 七类基金的映射规则

### 4.1 `index_plain` — 普通指数基金

- **规则 ID**：`R-INDEX`
- **主基准来源**：目标指数
- **必须分开记录**：目标指数代码；目标指数的收益口径
- **候选条件**：指数代码已映射且有历史行情
- **可用条件**：**收益口径已确认（非 unknown）** + 研究规则已声明
- **降级条件**：收益口径 unknown → 只能标记候选

| 禁止 |
| --- |
| 不得统一映射到沪深300 |
| 不得用价格指数冒充全收益指数 |
| 不得因基金名称含行业词就猜行业指数 |

### 4.2 `etf_feeder` — ETF联接基金

- **规则 ID**：`R-FEEDER`
- **主基准来源**：目标指数（非目标 ETF 的市场价格）
- **必须分开记录**：目标 ETF 代码；目标 ETF 场内价格；目标指数代码
- **候选条件**：目标指数已映射且有历史行情
- **可用条件**：目标指数收益口径已确认
- **降级条件**：仅有 ETF 价格、无指数口径 → 置信度降为 C

| 禁止 |
| --- |
| **不得把目标 ETF 的二级市场价格收益当作指数收益** |
| 不得用 ETF 折溢价代替指数表现 |
| 不得因为目标 ETF 有价格就认定指数收益可用 |

### 4.3 `active_equity` — 主动权益基金

- **规则 ID**：`R-ACTIVE`
- **主基准来源**：合同基准 + 投资范围 + 可比研究指数
- **必须分开记录**：A股暴露；港股暴露；行业主题暴露
- **候选条件**：合同基准含已映射指数，或投资范围明确可对标
- **可用条件**：收益口径已确认 + 研究选择理由已声明
- **降级条件**：无投资范围证据 → 置信度降为 C

| 禁止 |
| --- |
| 不得把研究选择的指数写成合同基准 |
| 不得仅因名称相似就强制匹配指数 |
| 不得跨市场混用（A股指数替代港股基准） |

### 4.4 `pure_bond` — 纯债基金

- **规则 ID**：`R-PUREBOND`
- **主基准来源**：与久期/债券类型匹配的债券指数
- **必须分开记录**：利率债 / 信用债；短债 / 中长期；净价 / 全价 / 财富
- **候选条件**：债券指数已接入且口径匹配
- **可用条件**：债券指数口径已确认 + 久期类型匹配
- **降级条件**：债券指数全部未接入 → 置信度 D，不可用

| 禁止 |
| --- |
| **不得用国债收益率曲线替代债券指数收益序列** |
| 不得把净价、全价、财富指数混用 |
| 久期不匹配时不得直接映射 |

### 4.5 `mixed_bond` — 混合债券基金

- **规则 ID**：`R-MIXEDBOND`
- **主基准来源**：债券指数 + 权益指数的复合（保留全部成分与权重）
- **必须分开记录**：权益仓位；可转债风险；债券类型
- **候选条件**：成分全部识别且至少一个可用序列
- **可用条件**：全部成分可计算 + 口径已确认
- **降级条件**：缺权益或债券成分证据 → 置信度 C/D

| 禁止 |
| --- |
| 不得把可转债简单归类为纯债 |
| 不得忽略权益仓位 |
| 缺乏证据时不得假设仓位为 0 |

### 4.6 `money_market` — 货币基金

- **规则 ID**：`R-MONEY`
- **主基准来源**：万份收益 / 七日年化（独立口径）
- **必须分开记录**：万份收益；七日年化；节假收益结转规则
- **候选条件**：有万份收益或七日年化数据
- **可用条件**：展示口径与结转规则均已确认
- **降级条件**：仅有普通净值 → 置信度 D，不可用

| 禁止 |
| --- |
| **不得与普通净值基金混算** |
| 不得直接把 Shibor 或国债收益率当成货币基金收益 |
| 不得用净值增长率替代万份收益 |

### 4.7 `lof_offexchange` — LOF场外份额

- **规则 ID**：`R-LOF`
- **主基准来源**：**场外份额净值**（非场内交易价格）
- **必须分开记录**：场内交易代码；场外申购代码；A/C 份额
- **候选条件**：场外份额净值可得
- **可用条件**：场外净值口径确认 + 底层投资类型基准可用
- **降级条件**：仅有场内价格 → 置信度 D，不可用

| 禁止 |
| --- |
| **不得使用场内市场价格或折溢价替代场外净值** |
| 不得因名称含 LOF 就套用场内价格 |
| A/C 份额不得重复统计基金本体 |

## 5. 复合基准映射规则

| 规则 | 内容 |
| --- | --- |
| 成分完整性 | **不得把复合基准简化为单一指数** |
| 权重语义 | 固定年化收益率（``fixed_rate``）与资产配置权重（``asset_weight``）必须严格区分，不得相加 |
| 利率分类 | 现金利率 / 存款利率 / 回购利率 / 固定收益率分属不同类别，不得混为一类 |
| 口径分类 | 价格指数 / 全收益指数 / 债券净价 / 全价 / 财富指数不得混用 |
| 未知权重 | 权重无法验证时必须标记 ``None``，不得推断 |
| 历史权重 | **历史权重和基准变更生效日期未知时，不得假设当前权重在历史上一直有效** |
| 阻断规则 | **任一必要成分不可计算，完整合同基准就不能标记为可复现** |
| 不放宽 | 不得为了提高可用数量而放宽标准；此前已审计的 15 条复合基准均不可完整复现，本轮结论不变 |

## 6. 映射置信度（四级，3B-6.2.2.1.1 修正边界）

| 级别 | 标签 | 定义 |
| --- | --- | --- |
| **A** | 高 | L1 官方合同证据、映射关系明确、收益口径确认、全部必要成分可计算 |
| **B** | 中高 | 映射关系有可靠的 L1/L2 证据、基准身份明确、**不存在关键映射缺口**，可存在非关键缺口 |
| **C** | 中低 | 存在合理候选映射，但关键证据缺失，包括仅有 L3 第三方资料、收益口径未确认、必要成分不完整等 |
| **D** | 低 | 分类或映射依据严重不足，无法建立可靠候选关系 |

### 6.1 各级的硬性条件

| 级别 | 必要条件 | 非关键缺口可容忍 |
| --- | --- | --- |
| **A** | L1 官方合同文件 + 映射在合同中明确写出 + 收益口径已确认 + 全部必要成分可计算 | 否 |
| **B** | **L1 或 L2 映射证据** + 基准身份（用哪个指数）明确 + **无关键映射缺口** | 是 |
| **C** | 有可识别的候选指数（含仅识别到指数名但代码未映射、债券指数未接入） | — |
| **D** | 无任何可识别候选映射 | — |

### 6.2 关键缺口 vs 非关键缺口（本轮核心修正）

**映射身份的证据可靠，不代表复合基准的必要成分完整。两者必须分别判断。**

| 缺口类型 | 具体情形 | 后果 |
| --- | --- | --- |
| **关键缺口** | 指数名识别到但**代码未映射** | L1/L2 也只能 **C** |
| **关键缺口** | **债券指数未接入**（中债/中证债券指数无序列） | L1/L2 也只能 **C** |
| **关键缺口** | 复合基准**未解释的剩余权重**（成分构成无法确认） | L1/L2 也只能 **C** |
| **关键缺口** | 复合基准**成分权重无法确认** | L1/L2 也只能 **C** |
| **关键缺口** | 成分类型无法识别 | L1/L2 也只能 **C** |
| 非关键缺口 | **收益口径 `unknown`**（不影响「是哪只指数」） | 可评 **B**，但基准不可用 |
| 非关键缺口 | **现金利率无历史序列** | 可评 **B**，但基准不可用 |
| 非关键缺口 | **固定收益率折算规则未知** | 可评 **B**，但基准不可用 |
| 非关键缺口 | **未持有官方合同原始文件**（不影响身份，只影响合同基准准入） | 可评 **B**，但基准不可用 |

代码实现：`assess_benchmark_usability()` 输出 `has_critical_mapping_gap` /
`critical_gaps` / `non_critical_gaps` / `required_components_complete`，
`map_fund_benchmark()` 把该状态从**真实解析结果**传给 `compute_confidence()`，
不是测试手工构造。

### 6.3 关键边界

| 规则 | 说明 |
| --- | --- |
| **仅有 L3 第三方平台文本 → 最高只能 C** | 无法证明「合同里写的确实是这只指数」 |
| **有 L1/L2 证据但存在关键缺口 → 也只能 C** | 身份可靠 ≠ 必要成分完整 |
| **收益口径 `unknown` 本身不直接判 D** | 在 L1/L2 证据且无关键缺口时属非关键缺口，可评 B |
| **B 级也不代表可用** | 口径未确认 → 基准仍不可用 |
| **不得为保留 B 级数量而放宽证据要求** | 无 L1/L2 证据就是 C |
| **D 级只由「无候选映射」或「分类降级」触发** | 不因收益口径 unknown 触发 |
