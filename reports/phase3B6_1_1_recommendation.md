### 1.1 缺口性质

| 缺口天数 | 性质 | 是否数据缺失 |
| ---: | --- | --- |
| 1~3 天 | 周末 | **否** |

## 3. 日度化方法对比

### 3.1 两种公式

| 方法 | 公式 |
| --- | --- |
| A 简单折算 | `daily = annual / 365` |
| B 复利折算 | `daily = (1 + annual) ** (1/365) - 1` |

### 3.2 量化差异

| 期限 | 行数 | A 日均 | B 日均 | 日均差 | 相对差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `1年` | 5,185 | 0.0000657865 | 0.0000649366 | -8.499e-07 | -1.2919% |
| `3年` | 5,185 | 0.0000742285 | 0.0000731737 | -1.055e-06 | -1.4210% |

**结论**：B 在每个期限上都**略小于** A（因复利折现），差异量级 **1e-6**，
相对差异约 **1.3%~1.4%**（相对于日均收益本身）。

### 3.3 对 Sharpe 的可能影响（**未实算**）

> 本轮禁止修改 Sharpe 公式，也不做基金绩效结论；差异量级已量化（见 daily_diff_*），如需 Sharpe 敏感性演示须另立研究性临时样本并明确标注

**量级估计**：以年化 3% 为例：A 日收益 8.219e-5，B 日收益 8.098e-5，差 1.21e-6；对日波动率约 1% 的基金，Sharpe 影响量级 < 0.001

**这是量级估计，不是 Sharpe 实算结果，不得引用为绩效结论。**

### 3.4 周末与节假日

| 处理方式 | 评价 |
| --- | --- |
| A. 保持原样，按交易日对齐 | **推荐** |
| B. 前向填充到自然日 | 会改变日频统计量，不推荐 |
| C. 置 0 | **错误**，相当于无风险收益为 0 |

**前向填充与日度化公式是两件事，不可混谈。**

## 4. 不同基金类别的适用性（候选，非正式口径）

### 4.1 前提：四种利率不可混用

| 概念 | 是什么 | 不是什么 |
| --- | --- | --- |
| 无风险利率 | 理论上无违约无波动的收益 | **不等于**基金合同业绩基准 |
| 国债收益率 | 政府债券到期收益率 | **不等于**债券指数收益率 |
| Shibor | 银行间同业拆借利率 | **不等于**银行活期存款利率 |
| 上证国债指数 | **债券投资指数** | **不是利率** |

### 4.2 分类建议

| 基金类别 | 候选代理 | 理由 | 代价 / 限制 |
| --- | --- | --- | --- |
| 股票指数 / ETF联接 | **1 年期国债** | 短端、波动小、贴近无风险 | 仍非真正无风险；需 T+1 滞后 |
| 主动权益 | **1 年期国债** | 同上 | 同上 |
| 纯债基金 | **1 年期或 3 年期**（待定） | 与债券久期更匹配 | **3 年期 vs 1 年期结论不同，不可随意选** |
| 混合债券 | **1 年期或 3 年期**（待定） | 同上 | 同上 |
| 货币基金 | **Shibor 或 1 年期国债** | 更贴近货币市场 | Shibor 仅 2015 起，**覆盖不足** |

### 4.3 货币基金的特殊问题

| 问题 | 说明 |
| --- | --- |
| Shibor 覆盖 | 2015-05-08 起，**无法覆盖 2006~2014** |
| 万份收益 / 7 日年化 | **不能直接套用**普通权益基金口径 |
| 若强行统一用 1 年期国债 | 会低估货币基金的真实无风险收益 |

### 4.4 明确不做的事

| 项 | 状态 |
| --- | --- |
| 确定统一无风险利率 | **否** |
| 确定日度化公式 | **否** |
| 确定滞后天数 | **否**（只建议 T+1） |
| 计算任何 Sharpe | **否** |
