## 3. 指标必须携带的元信息

每个指标结果必须包含：

| 字段 | 说明 |
| --- | --- |
| `start_date` / `end_date` | 计算起止日 |
| `span_days` | 自然日跨度 |
| `status` | `ok` / `insufficient_data` / `not_available` |
| `reason` | 不可计算时的**具体原因** |
| `field` | 使用的净值口径（`acc_nav` / `unit_nav` / `money_yield`） |

---

## 4. 净值口径规则

| 场景 | 用什么 | 禁止 |
| --- | --- | --- |
| 净值型基金总回报 | **`acc_nav`**（累计净值，含分红再投资） | 用 `unit_nav` 冒充 |
| 单位净值观察 | `unit_nav` | 当总回报用 |
| 货币基金 | 每万份收益 + 7 日年化 | 与净值型混算 |
| 分红表 | 仅作证据记录 | 用它修复历史收益 |

**为什么不用分红表修复**：`acc_nav` 本身已含分红再投资，
审计实测「有分红但 `acc_nav == unit_nav`」= **0** 只，
说明累计净值确实反映了分红，无需二次修补。

---

## 5. 缺口处理规则

| 规则 | 阈值 / 实现 |
| --- | --- |
| 超阈值缺口 | `MAX_GAP_DAYS_FOR_RETURN = 15` 天 |
| 缺口跨越区间 | 直接 `insufficient_data`，**不计算** |
| 缺失日收益 | **不填 0** |
| 端点缺失 | **不向前后找最近值** |
| 滚动窗口 | 逐窗口独立检查缺口与空值 |

---

## 6. 年化规则

| 条件 | 处理 |
| --- | --- |
| 区间 < 365 天 | **不年化**，返回 `insufficient_data` + 原因 |
| 区间 >= 365 天 | 按自然日年化 `(1+r)^(365/days) - 1` |
| 频率未确认 | 波动率等不给年化值 |

**不使用固定 252**：那是美股惯例，本项目从实际观测密度推导。

---

## 7. 公平比较窗口

| 方式 | 实现 | 适用 |
| --- | --- | --- |
| 共同历史区间 | `common_window` 取所有参与者的交集 | 组内横向比较 |
| 滚动窗口 1Y | `rolling_windows(365)` | 稳定性 |
| 滚动窗口 3Y | `rolling_windows(1095)` | 中期稳定性 |
| 成立以来 | 仅作参考，**不用于跨基金比较** | 单个基金描述 |

**铁律**：成立时间不同的基金**不得**直接比较「成立以来收益」。

---

## 8. 稳定性判定

| 项 | 阈值 | 含义 |
| --- | --- | --- |
| 最小有效滚动窗口 | 5 个 | 少于 5 个 → `insufficient_data` |
| 最佳窗口依赖 | 最佳收益 − 中位数 > 区间宽度 × 0.5 | 标记 `high_dependency` |
| 剔除最佳窗口 | 剔除后正收益比例是否跌破 0.5 | 检验稳健性 |

| --- | --- |

## 10. 质量等级继承

沿用 3B-5.5 的 A/B/C/D：

| 等级 | 含义 |
| --- | --- |
| A | 数据完整、可验证、样本充足 |
| B | 数据基本完整，个别维度受限 |
| C | 小样本或部分字段缺失 |
| D | 不可验证 / 关键字段 unknown |

**`bond_pure|unknown` 必须 D**，与数量无关。
