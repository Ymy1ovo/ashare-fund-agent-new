### 4.3 日期语义：这是平台观测日期，不是验证过的报告期末

> **本节是 3B-4.4 验收修正的核心。** 原报告把 675 条记录的日期
> 一律当成「报告期末」并宣称可作为时点特征——**这个结论缺乏证据，已撤回。**

| 项 | 修正前 | 修正后 |
| --- | --- | --- |
| 日期语义 | `report_date_is_period_end = true` | **`date_semantics = platform_observation_date`** |
| 报告期末已核实 | **true（错）** | **`period_end_verified = false`** |
| 公告发布日期已核实 | **false** | **`publication_date_verified = false`** |
| 可作为时点特征 | **true（错）** | **`point_in_time_usable = false`** |
| `disclosed_at` | 全 NULL | **全 NULL（不变）** |

**为什么必须撤回**：从 `reports/evidence/phase3b4_4/aum_history.json` 里
能直接看到大量非季末日期：

| 日期 | 类型 |
| --- | --- |
| `2010-08-23` ~ `2010-09-08` | 周频/日频（连续多日同值） |
| `2013-03-08` / `2013-03-15` / `2013-03-22` / `2013-03-29` | 周频 |
| `2013-04-03` / `2013-04-12` | 非标准季度末 |
| `2018-06-29` / `2018-12-28` | 月末而非季末 |

统计：138 个不同日期中，**84 个是季末、54 个不是季末**。

平台按周/月披露的日期不等于报告期末。把平台观测日直接当报告期末，
既没有逐条核实，也无法证明投资者在该日已知晓该数据。

### 4.4 能否作为历史时点特征

**规模：`false`** —— 只能作为**带时间语义限制的描述性历史规模数据**。

| 用途 | 是否允许 |
| --- | --- |
| 描述性统计（「该基金某段时间的规模量级」） | ✅ 允许 |
| 作为历史时点因子（规模因子、规模择时） | ❌ **禁止**（未来信息泄漏） |
| 作为正式回测的已知信息 | ❌ **禁止** |
| 作为「某日规模」的精确断言 | ❌ **禁止** |

**核心问题**：即使某个日期确实是报告期末，也不代表投资者在该日已经知道这个数据。
`disclosed_at` 全为 NULL，**公开可见时间完全 unknown**。

使用条件：

- 仅可用于描述性统计
- 不得把平台日期当作报告期末或公告日
- 中间缺失就是缺失，不得插值
- C 级证据：来自天天基金规模变动页
- 货币基金规模单位是亿元但量级巨大（余额宝），注意单位

**没有做的事**：

- 没有用当前规模代表历史规模
- 没有插值填补缺失期
- 页面显示 `---` 的期次跳过，**未填 0**（`skipped_undisclosed` 计数单独记录）
