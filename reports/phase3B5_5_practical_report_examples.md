### 11.2 有条件的描述性判断

- 近1年收益 -4.0993%：窗口端点精确命中、窗口内无超阈值缺口，可作**描述性**事实；但不能据此推断未来

### 11.3 目前无法证明的事项

- 超额收益 / 信息比率 / Beta：库内无基准收益序列
- 同类比较：同类样本不足（拒绝强行构造同类排名）

## 11. 研究结论

### 11.1 数据支持的事实

- 数据覆盖 2015-07-16 ~ 2026-11-20，共 2764 条记录
- 净值连续性为 cannot_verify（无真实基金公布日历，无法验证每个交易日是否都该有净值）
- 主要收益口径为 acc_nav（累计净值，含分红再投资代理）
- 分红修复未使用（dividend_repair_used=False）

### 11.2 有条件的描述性判断

- 近1年收益 -3.3548%：窗口端点精确命中、窗口内无超阈值缺口，可作**描述性**事实；但不能据此推断未来
- 近3年收益 25.2756%：窗口端点精确命中、窗口内无超阈值缺口，可作**描述性**事实；但不能据此推断未来
- 最大回撤 39.1939% 覆盖全区间，但净值连续性仍未验证

### 11.3 目前无法证明的事项

- 未来收益：本项目不做任何收益预测
- 支付宝可购买状态：无公开合法数据源，恒 unknown
- 支付宝实际费率：不可验证，不用天天基金费率冒充
- 真实净值公布日历：不可得，连续性恒 cannot_verify
- Sharpe / Sortino：无可靠无风险利率，拒绝计算（不把 0 当利率）
- 超额收益 / 信息比率 / Beta：库内无基准收益序列
- 同类比较：同类样本不足（拒绝强行构造同类排名）
- A/C 成本优劣结论：费率字段不完整，标 insufficient_fee_evidence

## 12. 结论限制

| 用途 | 是否允许 |
| --- | --- |
| 描述性历史观察 | ✅ |
| 未来收益预测 | ❌ |
| 买入或卖出建议 | ❌ |
| 跨类别正式排名依据 | ❌ |
| 单一年度收益推导长期结论 | ❌ |

- 净值连续性 cannot_verify（无真实公布日历）
- 分红记录不完整，未用其修复历史收益

- 同类样本量小，只能描述性对照
- 不构成投资建议，不预测未来收益
