## 7. 分级标准与结果

### 7.1 分级定义

| 等级 | 证据要求 |
| --- | --- |
| **A** | 官方身份 + 收益口径 + **真实起点确认** + **官方日历** + 数据质量 + **时点可用** |
| **B** | 官方身份 + 收益口径 + 数据质量，且日历至少**代理**验证 |
| **C** | 官方身份 + 收益口径通过，但日历或质量存在未解决限制 |
| **D** | 存在严重质量问题 |
| **UNKNOWN** | 关键证据不足 |

### 7.2 分级结果

| 等级 | 数量 | 候选 |
| --- | ---: | --- |
| **A** | **0** | — |
| **B** | **8** | `399997CNY02` `H00016` `H00300` `H00905` `H00906` `H00922` `H00942` `H20539` |
| **C** | **4** | `H00012` `H20184` `H20930` `N00012` |
| D | 0 | — |
| UNKNOWN | 0 | — |

### 7.3 为什么没有 A 级

A 级要求**六项全部有充分证据**。当前：

| 维度 | 通过数 |
| --- | ---: |
| 官方身份 | 12 / 12 |
| 收益口径 | 12 / 12 |
| 数据质量 | 11 / 12 |
| **真实历史起点** | **0 / 12** |
| **官方交易日历** | **0 / 12** |
| **历史时点可用性** | **0 / 12** |

**三项关键证据全为 0，因此 A 级必然为 0。**

### 7.4 为什么 B 级不能升为 A

B 级候选（8 个股票全收益）虽然身份、口径、质量、代理日历都通过，
但**代理日历 ≠ 官方日历**，**真实起点 unknown**，**时点 unknown**。

**三项缺口均属「关键证据不足」，不得因其他维度通过而升级。**
