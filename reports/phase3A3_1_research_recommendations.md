# 阶段3A.3.1 研究方向评估与优先级建议

- 编写时间：2026-11-12
- 前置依据：`reports/phase3A3_1_attribution_report.md`（本轮实测）
- 性质：**可行性评估**，不实现任何策略，不产生任何回测结论

> 本文件只回答「值不值得做、先做哪个、怎么做才不容易自欺」，不回答「哪个策略能赚钱」。

## 1. 归因结论对方向的约束

先把本轮**实测**的结论列清楚，后面的评估只能建立在它们之上：

| 编号 | 实测结论 | 数据 |
| --- | --- | --- |
| F1 | MA250 与等权买入持有几乎打平 | 31.79% vs 31.97% |
| F2 | MA250 成本是买入持有的 15.2 倍 | 10,639.52 vs 697.70 元 |
| F3 | 成本抹平了 8,181 元的毛利优势 | 成本差 9,942 元 > 毛利差 |
| F4 | MA250 风险指标全面更差 | 波动 24.13% vs 20.83%；回撤 -25.12% vs -18.58% |
| F5 | 组合层面几乎从未降仓 | 空仓 1 天，平均暴露 97.70% |
| F6 | 震荡市 43.3% 的交易换来更低收益 | 184 笔，+13.98% vs +17.63% |
| F7 | 30.86% 的卖出在 5 日内往返 | 50 / 162 笔 |
| F8 | 原始价格存在 22 处份额折算断点 | 样本外 6 + 样本内 16 |

**方向筛选的第一原则**：F8 未解决前，任何依赖绝对收益数字的对比都不可信。
所以下一阶段**必须**先修数据口径，再谈策略方向。

## 2. 五个方向的逐项评估

### 方向 A：简单等权持有 + 定期再平衡

| 项目 | 内容 |
| --- | --- |
| 理论上解决什么问题 | 直接针对 F2/F3（换手成本）与 F5（无组合级调仓纪律）：把「天天判断」变成「按固定周期拉回目标权重」，换手由周期决定而非信号抖动决定 |
| 需要哪些数据 | 现有 41 只 ETF 的行情 + 交易日历，**不需要新数据** |
| 潜在优势 | 参数极少（只有再平衡周期：月/季/半年）；可直接与买入持有、MA250 三方对照；成本可预测（每年 N 次 × 只数 × 最低佣金） |
| 主要风险 | 在趋势性行情里再平衡会持续卖出涨得多的、买入跌得多的，可能拉低收益；A 股行业轮动快时可能「越平衡越差」 |
| 是否容易过拟合 | **低**。再平衡周期只有 3~4 个候选值，且事前可枚举，不存在参数曲面搜索 |
| 预计交易频率 | 月频：每年 12 次 × 41 只 ≈ 492 笔；季频 ≈ 164 笔；半年频 ≈ 82 笔 |
| 是否值得进入下一阶段 | **强烈建议，且应排第一** |

理由：它是唯一能同时验证「换手成本假设」与「再平衡是否能改善风险」的**最小实验**。
如果季频再平衡在同样成本下都不能改善风险调整收益，那说明「等权持有」本身已经接近
这段样本的最优，后续所有复杂配置的边际价值都会被大幅压缩。

### 方向 B：基于波动率的风险预算配置

| 项目 | 内容 |
| --- | --- |
| 理论上解决什么问题 | 针对 F4/F5：按波动率倒数分配权重，让高波动标的自动降权，从而在**不预测方向**的前提下降低组合波动 |
| 需要哪些数据 | 现有行情即可计算滚动波动率；需要明确窗口（20/60/120 日）与上限约束 |
| 潜在优势 | 不依赖收益预测；对「高波动资产拖累组合」有直接抑制作用；与再平衡天然兼容 |
| 主要风险 | 波动率聚集会让组合在恐慌期集中降权，反而错过反弹；权重上限/下限的设定会引入主观参数 |
| 是否容易过拟合 | **中**。窗口 × 上下限 × 再平衡频率三维搜索很容易过拟合，必须限定枚举组合并做样本外一次性验证 |
| 预计交易频率 | 与再平衡频率同步；波动率变化剧烈时换手会显著高于等权 |
| 是否值得进入下一阶段 | **建议排第二**，但必须在方向 A 之后，且必须先修数据口径 |

理由：本轮已观测到 MA250 波动率高于买入持有 3.3pp，说明「等权」在波动维度并非最优。
但风险预算的有效性依赖波动率估计的稳定性，A 股 ETF 的滚动波动率在 2021-2026 期间
变化很大，需要先确认「波动率与未来波动率的相关性」是否足够高。

### 方向 C：简单趋势过滤 + 长期持有

| 项目 | 内容 |
| --- | --- |
| 理论上解决什么问题 | 保留趋势信号，但把「逐只判断 + 立即满仓替换」改成「整体风险开关 + 长期持有」，避免 F7 的反复往返 |
| 需要哪些数据 | 现有行情 + 一个市场级代理（510300） |
| 潜在优势 | 若趋势信号真的含信息，用「整体开关」而非「逐只开关」可以把换手从 425 笔降到个位数 |
| 主要风险 | **这是 MA250 的近亲**，很容易变成「换了个包装继续调参」；本轮熊市只有 26 天，样本不足以验证开关有效性 |
| 是否容易过拟合 | **高**。触发阈值、确认天数、代理标的选择都是自由度 |
| 预计交易频率 | 极低（每年 0~4 次整体切换） |
| 是否值得进入下一阶段 | **暂缓**。除非先修完数据口径并在更长样本上确认「市场级趋势信号有预测力」，否则只是重复 MA250 的错误 |

理由：本轮已经证明**个股级**趋势过滤在这段样本没有风控效果。改成市场级是否会好，
属于**未验证假设**。在没有更长样本（至少覆盖一轮完整牛熊）之前，做这个方向的
任何回测都无法区分「真有效」与「恰好这段样本有效」。

### 方向 D：资产类别分散配置

| 项目 | 内容 |
| --- | --- |
| 理论上解决什么问题 | 针对 F4（回撤更深）：股票 / 债券 / 黄金 / 海外在同一组合里低相关，理论上能降低组合波动 |
| 需要哪些数据 | 现有 46 只 ETF 已覆盖股票（宽基/行业）、债券（国债/城投/公司债/短融）、黄金、海外（纳指/标普/日经/德国/恒生）——**数据已具备** |
| 潜在优势 | 分散是唯一「不靠预测」的风险来源；本轮样本外黄金 +40%~49%、纳指 +30%，与 A 股相关性明显较低 |
| 主要风险 | 类别权重仍需主观设定；极端行情下相关性会趋同（2020 年 3 月、2022 年全年都出现过）；债券 ETF 存在流动性折价 |
| 是否容易过拟合 | **中低**。若只用「固定类别权重 + 定期再平衡」，自由度只有 3~5 个权重比 |
| 预计交易频率 | 与再平衡频率一致 |
| 是否值得进入下一阶段 | **建议与方向 A 合并验证**（A + D = 等权分散 + 再平衡） |

理由：方向 A 单独做只是「股票内部等权」，方向 D 补上「跨类别」这一层，
才是真正的风险分散。两者共用同一套再平衡框架，边际实现成本很低。

### 方向 E：波动率控制与现金管理

| 项目 | 内容 |
| --- | --- |
| 理论上解决什么问题 | 直接针对 F5（从不降仓）：按目标波动率动态调整股票仓位，剩余部分放现金/短债 |
| 需要哪些数据 | 现有行情 + 短融/国债 ETF 作为现金替代（已有 `511360`、`511010`） |
| 潜在优势 | 是唯一能**真正改变风险敞口**的机制；理论上能把回撤压到目标区间 |
| 主要风险 | **波动率目标在下跌初期会滞后降仓**（波动率上升往往滞后于价格下跌），可能既没躲过跌，又在低位降仓；目标波动率本身是主观参数 |
| 是否容易过拟合 | **高**。目标波动率 × 窗口 × 调仓频率 × 上下限，搜索空间很大 |
| 预计交易频率 | 中高（每次调整仓位都要成交） |
| 是否值得进入下一阶段 | **建议排最后**，且必须先完成 A/B，确认「已有方案的风险水平」之后再判断是否还需要额外控制 |

理由：本轮最关键的发现之一是「MA250 从未真正降仓」。方向 E 是直接的解药，
但也是最容易过拟合的解药。如果在没有基线的情况下直接做 E，很可能得到一个
「回撤很小但收益也被砍掉一半」的组合，然后误以为找到了答案。

## 3. 优先级排序与理由

| 优先级 | 方向 | 理由 |
| ---: | --- | --- |
| **P0（前置）** | 数据口径修复（阶段3A.3.2） | F8 未解决前，任何绝对收益对比都不可信；22 处断点必须先建事件表 |
| **P1** | A：等权持有 + 定期再平衡 | 最小实验，参数最少，直接检验「换手成本」假设 |
| **P1（与 A 合并）** | D：跨类别分散 | 与 A 共用再平衡框架，边际成本低，直接针对回撤 |
| **P2** | B：波动率风险预算 | 依赖波动率估计稳定性，需先确认相关性 |
| **P3** | C：市场级趋势过滤 | 本轮证明个股级无效；市场级需更长样本，否则无法区分真假 |
| **P4** | E：波动率目标 + 现金管理 | 最容易过拟合，必须等基线清晰后再做 |

**一句话**：先修数据，再做「少参数、可证伪」的方案，最后才做「多参数、易拟合」的方案。

## 4. 下一阶段最值得验证的一个方向（明确回答）

**方向 A：简单等权持有 + 定期再平衡。**

具体到可执行的实验设计（本阶段不实现，仅给方案）：

| 项目 | 设定 |
| --- | --- |
| 标的池 | 沿用验证记录的 41 只（不删、不换） |
| 权重 | 等权 |
| 再平衡周期 | 月 / 季 / 半年 / 年，四个候选，**一次性全部跑完，不挑最优** |
| 区间 | 沿用 2025-01-02 ~ 2026-11-09（与 MA250 完全同区间） |
| 成本 | 沿用同一 `CostConfig` |
| 对照 | 买入持有（不再平衡）、MA250 |
| 判定标准 | 若任一周期在**同样成本口径下**风险调整收益优于买入持有 → 值得继续；否则说明「再平衡无增量价值」 |
| 必须报告的 | 每个周期的换手笔数、成本、收益、波动、Sharpe、最大回撤、逐年表现 |

**证伪条件（先写清楚，避免事后解释）**：
若四个周期全部不能在同成本口径下改善 Sharpe 或 Calmar，则**判定方向 A 无增量价值**，
并直接进入方向 B/D 的联合评估；不得通过增加周期档位或调整权重上限来「找回」结果。

## 5. 明确不做的事

- 不因为某个方向「听起来合理」就认定它有效；
- 不在本阶段实现任何策略原型；
- 不在数据口径问题未解决时给出任何「修正后收益」的正式数字；
- 不把本轮的任何样本外结果外推为未来收益；
- 不进入 3B，不接入券商接口，不做自动下单。
