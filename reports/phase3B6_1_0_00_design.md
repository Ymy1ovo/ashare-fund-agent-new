## 2. 审计方法

| 步骤 | 做法 |
| --- | --- |
| ① 官方证据 | 下载并解析中证指数公司**编制方案 PDF 原文** |
| ② 实际调用 | 逐指数逐一调用接口，记录请求参数/返回/行数/日期/异常 |
| ③ 数值核验 | 对比价格与全收益**同日点位**，确认是不同序列 |
| ④ 交叉验证 | 用「接口返回的指数中文全称」与官方方案比对 |
| ⑤ 记录 | 全部原始结果落盘 `.tmp610/raw/`，报告可复算 |

### 2.1 明确的禁止项

| 禁止 | 说明 |
| --- | --- |
| 按名称猜口径 | 必须看官方方案 + 实际返回值 |
| 代码相同就认为是同一序列 | 价格/全收益/净收益是**不同代码、不同数值** |
| 把接口字段名当官方口径证明 | 字段名不是编制方案 |
| 价格指数冒充全收益 | 已实测数值不同 |
| 净收益冒充全收益 | 两者定义不同 |
