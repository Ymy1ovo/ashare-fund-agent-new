## 1. 对照文件映射错误修正

### 1.1 错误详情

```python
# 修正前（错误）
f = EVID_OLD4 / f"csindex_ctrl_{code}_from20040102.json"   # code 是候选代码
```

但 3B-6.2.3.0.4 保存的对照文件**用的是原价格指数代码**：

| 候选 | 应查的对照文件 | 修正前实际查找 |
| --- | --- | --- |
| `H00016` | `csindex_ctrl_000016_from20040102.json` | ❌ `..._H00016_...`（不存在） |
| `H00300` | `csindex_ctrl_000300_from20040102.json` | ❌ `..._H00300_...`（不存在） |
| `H20184` | `csindex_ctrl_H30184_from20040102.json` | ❌ `..._H20184_...`（不存在） |
| `H00012` / `N00012` | `csindex_ctrl_000012_from20040102.json` | ❌ 均不存在 |
| `H20930` | `csindex_ctrl_930930_from20040102.json` | ❌ `..._H20930_...`（不存在） |

**实测：3B-6.2.3.0.4 只有 10 份对照文件，全部是原价格指数代码，没有任何全收益候选的对照文件。**

### 1.2 修正后：严格区分两种对照证据

| 字段 | 含义 | 本轮结果 |
| --- | --- | --- |
| **`price_index_control`** | 原**价格指数**的对照请求是否确认 `20040101` 消失 | **12/12 有** |
| **`tr_candidate_control`** | **全收益候选自身**的独立对照证据 | **0/12 有** |

**原价格指数的对照结论，只能证明原价格指数接口的行为，不能自动证明全收益候选具有相同行为。**

**本轮无任何全收益候选自身的对照请求证据**——即 `tr_candidate_control` 为 `0/12`。

### 1.3 reason 生成逻辑修正

**修正前**：即使 `control=None`，仍固定生成「对照实验证实改起始日后消失」。

**修正后**：逐项生成，证据不存在时**不得声称通过**。

示例（`H00300` 实际输出）：

> 4 项独立证据支持合成行（请求起始日/非交易日/数值重复/早于基日），
> 但**无 H00300 自身对照证据**，故为高置信推断，**非官方确认**

## 4. 休市日占位行分类保守化

### 4.1 修正前的过宽规则

```python
if zero_vol and (same_as_prev or tiny_pct):
    cls = "market_closed_placeholder"   # 直接确认
```

**问题**：

- 零成交量本身不能证明占位；
- 小幅涨跌本身不能证明占位；
- 收盘值变化但 `changePct` 很小，不能直接认定无效。

### 4.2 修正后：三态

| 状态 | 条件 | 本轮 |
| --- | --- | --- |
| `confirmed_market_closed_placeholder` | 有**官方交易日历/发布规则/足够直接证据** | **0**（本轮无官方日历证据） |
| `suspected_market_closed_placeholder` | 有零成交、数值重复等特征，但**无足够直接证据** | **7** |
| `unexplained` | 无法解释 | **0** |
