## 3. 接口异常行为（实测）

| 场景 | 行为 |
| --- | --- |
| 传 `YYYY-MM-DD` 格式 | **抛 ValueError: No tables found** |
| 跨 2 年请求 | 返回 **0 行**（不报错） |
| 未来年份（2030） | 返回 0 行 |
| 起止倒置（2024-12-31 → 2024-01-01） | 返回 0 行 |
| 单日请求 | 返回 3 行（3 条曲线） |

**重要**：「返回 0 行」不等于「该期间无数据」，也可能是**跨度过大导致的静默失败**。
本轮因此改为**按半年分段**（42 段全部成功）。

---

## 4. 重复调用一致性（本轮实测）

| 项 | 结果 |
| --- | --- |
| 同区间两次调用 | **sha256 完全相同** |
| 跨区间同日重叠（61 天） | **数值差异 0** |

**结论**：短周期内未观察到数据修订。**但这不能排除更长时间跨度的修订。**
