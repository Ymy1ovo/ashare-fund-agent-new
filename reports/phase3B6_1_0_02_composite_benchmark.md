## 0. 本轮修正的实质错误

### 0.1 `000051` 的 1% 被错当成资产权重

**原始基准文本**：

> 沪深300指数收益率×95%＋1%（指年收益率，评价时应按期间折算）

| 项 | 3B-6.1.0（错误） | 3B-6.1.0.1（修正） |
| --- | --- | --- |
| 成分类型 | `fixed_rate` | **`fixed_annual_return`** |
| `weight` | **0.01**（错） | **`null`** |
| `annual_rate` | 无 | **0.01** |
| 期间折算 | 未记录 | **`period_conversion_required=true`，`method=unknown`** |

**为什么是错的**：`1%` 是**年化固定收益率**，不是 1% 的资产权重。
若当权重，则 95% + 1% = 96%，**权重合计不成立**。

**正确理解**：95% 配沪深300，剩余 5% 按 **1% 年化固定收益**计。

### 0.2 修正后的权重语义

| 项 | 值 |
| --- | --- |
| 资产权重成分合计 | **0.95** |
| 固定年收益率 | **1% / 年** |
| 期间折算方法 | **unknown**（合同只写「按期间折算」，未给公式） |

**不自行决定该 1% 如何日度化或期间折算。** 合同未提供（单利/复利、天数基准、起止点）四项要素。

| 状态 | 判定条件 |
| --- | --- |
| `reproducible` | 全部成分有序列 **且** 历史权重有证据 |

| `not_reproducible` | 指数成分中至少一个无全收益 **且** 缺其它要素 |

**修正后不再有「指数成分无全收益」这一缺口**（10 个指数全部取得全收益代码），
