## 2. 关键发现

### 2.1 `H30184` 存在 0 值收盘（真实数据缺陷）

| 项 | 值 |
| --- | --- |
| 指数 | `H30184` 中证全指半导体产品与设备指数 |
| 日期 | `2013-06-28` |
| 收盘 | **0.0** |
| OHLC | 全为 `NULL` |
| `quality_status` | **`valid`** ← 标记错误 |

**这是唯一一条非正收盘记录，且质量标记为 `valid`。**
若直接用于收益计算，`2013-06-28` 前后会产生 **-100% 的假跌幅**。

**处置建议**：需要单独的数据修复任务（见 4.2），本轮不改库。

### 2.2 `930930` 的 139 条「非 A 股交易日」是真实港股行情

| 项 | 值 |
| --- | --- |
| 不在 A 股日历的 `valid` 记录 | **139 条** |
| 样例 | `2015-01-01`（A股休市，港股开市）、`2015-02-18`（A股春节休市） |
| 结论 | **港股与 A 股交易日不同，不可套用 A 股日历** |

若误用 A 股日历，会把这 139 条真实行情判为「非交易日错误记录」，得出完全错误的结论。

## 3. 时点可用性：全部未通过

| 概念 | 结论 |
| --- | --- |
| 历史行情存在 | ✅ 50,603 行 |
| 当前采集时间可追溯 | ✅ 10 个批次 |
| **历史数据版本可追溯** | ❌ 每 (code, date) 仅 1 行 |
| **历史公开时间可证明** | ❌ 无证据 |
| **历史时点可用性可证明** | ❌ 无证据 |

**根本原因**：

```
collected_at = 2026-11-23  →  只证明「2026-11-23 采集过」
                             不证明「2020-01-02 那天该数据已公开」
row_fingerprint           →  只证明当前行内容
                             不证明历史版本未被修订
```

**没有历史快照、没有修订记录 → `point_in_time_verified = false`，不可推导。**

### 4.3 债券基准口径建议（`000012`）

| 可选口径 | 序列 | 适用 |
| --- | --- | --- |
| 全价（当前接入） | `000012` | 反映债券价格变动，**不含再投资** |
| 净价 | `H00012` | 不含应计利息，**低估票息收益** |
| 利息及再投资 | `N00012` | 含利息再投资，最接近总回报 |

**建议**：债券研究基准优先考虑 `N00012`（利息及再投资），但需先核验其官方日历与历史覆盖。**不得把 `000012` 全价当财富指数使用。**

### 4.4 研究基准口径建议

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| 用价格指数 | 已有数据、连续性好 | **系统性低估分红收益**（8 个股票指数年化低估约 1.5~2.5%） |
| 用全收益指数 `H` 系列 | 与基金累计净值口径可比 | 需新接入；官方接口可取但未入库 |
| 用净收益指数 `N` 系列 | 更接近税后实际 | 同上，且部分指数无 `N` 系列 |

**关键问题：基金累计净值含分红再投资，价格指数不含。**

**建议**：研究评价基准优先用**全收益指数**（`H` 系列），并在报告中声明「与合同基准（多为价格指数）的差异」。**合同基准保持不变。**
