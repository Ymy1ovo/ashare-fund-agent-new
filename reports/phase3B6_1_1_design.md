## 3. 五个分析维度

### 3.1 数据源鉴权与证据等级

| 项 | 值 |
| --- | --- |
| 接口 | `akshare.bond_china_yield` |
| 底层提供方 | 中债金融估值中心（中债登） |
| 曲线 | 中债国债收益率曲线 |
| 证据等级 | **L3_third_party_aggregated** |
| 理由 | 经 AKShare 聚合获取，底层提供方为中债登；**未取得中债登官方原始发布文件**，不得称为「官方原始数据已独立核验」 |

### 3.2 接口实测约束（本轮新发现）

| 约束 | 实测结果 |
| --- | --- |
| 日期格式 | YYYYMMDD（YYYY-MM-DD 会 No tables found） |
| 单次跨度 | 约 1 年（跨 2 年返回 0 行） |
| 历史起点 | **2006-03-01** |
| 2002~2005 | [2002, 2003, 2004, 2005] 全部 0 行 |
| 期限 | 3月, 6月, 1年, 3年, 5年, 7年, 10年, 30年 |
| **缺失期限** | **2年** |

> 该接口返回的列中**不存在 2 年期**。任务要求的 2 年期无法从本数据源取得，如实记录，不以 3 年期替代。

### 3.3 覆盖与质量

| 项 | 值 |
| --- | --- |
| 参考区间 | 2006-03-01 ~ 2026-12-31 |
| 实际日期范围 | 2006-03-01 ~ 2026-11-24 |
| 去重后行数 | 41,480 |
| 独立日期数 | 5,185 |
| 各期限共享日期索引 | **是** |

### 3.4 时点可用性

三个日期必须分开：

| 概念 | 定义 | 本轮证据状态 |
| --- | --- | --- |
| `observation_date` | 收益率对应的观察日期 | 接口「日期」字段，语义未获官方说明 |
| `publication_date` | 数据实际公开日期 | **未取得官方时刻证据** |
| `available_date` | 系统允许使用的最早日期 | **无法证明，建议 T+1** |

### 3.5 日度化公式

| 方法 | 公式 |
| --- | --- |
| A 简单折算 | `daily = annual / 365` |
| B 复利折算 | `daily = (1 + annual) ** (1/365) - 1` |

**两者不可混用，也不得与「前向填充」混为一谈。**
