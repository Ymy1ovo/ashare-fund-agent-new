## 1. 原始数据与规范化数据的执行顺序

### 1.1 修正前（有问题）

```
_to_rows → 字典去重 → 排序 → check_history_quality → 入库
```

问题：重复日期被字典覆盖、倒序被排序抹平，
**质量检查看到的已经是被清洗过的数据，等于形同虚设**。

### 1.2 修正后（正确）

```
_to_rows（保持原始顺序、保留重复行）
  → check_history_quality(原始 rows)
  → 硬性失败 → 记录审计 + 质量记录 → 拒绝入库（0 行）
  → 硬性通过 → 去重 → 排序 → 入库
```

| 项 | 修正前 | 修正后 |
| --- | --- | --- |
| 去重先于质检 | **是** | **否** |
| 排序先于质检 | **是** | **否** |
| 原始行数如实记录 | 否（去重后） | **是**（`rows_returned` 为原始行数）|
| 重复日期能被发现 | 否 | **是** |
| 日期倒序能被发现 | 否 | **是** |
