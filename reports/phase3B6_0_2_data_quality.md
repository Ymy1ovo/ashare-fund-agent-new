## 0. 本轮修正：原始数据先质检

### 0.1 问题

旧流程 `去重 → 排序 → 质检` 会让两类问题**永远检查不出来**：

| 问题 | 旧流程行为 | 后果 |
| --- | --- | --- |
| 原始返回重复日期 | 字典按日期覆盖，只留一条 | `no_duplicate_dates` 永远为 ok |
| 原始返回倒序 | `sorted()` 先排好 | `date_ascending` 永远为 ok |

### 0.2 修正后

```
原始 rows（保持顺序、保留重复）→ check_history_quality
  → 硬性失败 → 拒绝入库（index_daily 0 行）
  → 硬性通过 → 去重 → 排序 → 入库
```

### 0.3 验证方式

直接调用**真实采集入口** `collect_one()`，用模拟接口返回：

| 场景 | 模拟数据 | 预期 | 实测 |
| --- | --- | --- | --- |
| A 重复日期 | 5 行，其中 2 行同日期 | ok=False，0 行入库 | ✅ |
| B 日期倒序 | 倒序 5 行 | ok=False，0 行入库 | ✅ |
| C 正常 | 升序无重复 5 行 | 正常入库 5 行 | ✅ |
