## 1. 五道硬阻断

### 1.1 历史权重全部缺失（最关键）

| 项 | 结果 |
| --- | --- |
| `weight_effective_from` 有值 | **0/34 成分** |
| 历史权重可验证基准 | **0/15** |

**这不是「权重不确定」，而是「数据库根本没有历史权重字段值」。**
无法判断任何一条基准在成立至今的任一时点用的是哪套权重。

### 1.2 收益口径全部未确认

| 项 | 结果 |
| --- | --- |
| `return_basis_verified` | **0/15** |
| 合同明说口径的成分 | 3 个债券指数（全价/财富） |
| 合同未说口径的指数成分 | **全部股票指数** |

**「沪深300指数收益率」不指明是全收益还是价格。**
若误用价格指数，会系统性低估基准收益（分红部分）。

### 1.3 现金成分完全无数据

| 项 | 结果 |
| --- | --- |
| 现金成分数 | **16 个**（含 15 个 cash + 1 个 fixed_rate） |
| 有历史序列 | **0** |
| 名义权重合计 | 约 75% |

**每条基准都有 5%~10% 的现金类成分无法计算。**
即使股票和债券部分都算对，基准收益仍然算不出来。

### 1.4 中证综合债券指数完全阻断

| 项 | 结果 |
| --- | --- |
| 受影响基准 | `001938 中欧时代先锋`（10% 权重） |
| 阻断原因 | **AKShare 无中证系列债券指数接口** |
| 替代方案 | **禁止用国债收益率曲线代替** |

### 1.5 债券指数代码映射全部未确认

| 项 | 结果 |
| --- | --- |
| 官方代码确认 | **0/5** |
| 编制方案取得 | **0/5** |
| 与官方口径一致 | **0/5** |

**「中债总指数」这种写法在合同里存在，但在中债指数族系里有几十个候选。**
无法唯一映射到一个可复现的序列。

## 3. 文本一致性

| 项 | 数量 |
| --- | ---: |
| 文本完全一致 | **5/15** |
| 归一化后一致（仅符号/顺序差异） | **10/15** |
| **语义实质不同** | **4/15** |

**语义实质不同的 4 条**（必须确认以合同为准）：

| # | 基准 | composite 写法 | fund_master 写法 | 冲突点 |
| ---: | --- | --- | --- | --- |
| 18 | 招商中证白酒 | `活期存款利率(税后)` | `金融机构人民币活期存款基准利率（税后）` | 「活期存款利率」vs「基准利率」 |
| 20 | 建信中证500增强 | `银行活期存款利率(**税后**)` | `商业银行活期存款利率(**税前**)` | **税前 vs 税后** |
| 22 | 博时裕富沪深300 | `银行**活期存款**利率(税后)` | `银行**同业存款**利率` | **活期 vs 同业** |
| 23 | 华夏中证500联接 | `银行活期存款利率(税后)` | `人民币活期存款税后利率` | 表述差异（语义接近） |

### 3.1 两处最严重的语义冲突

**`000478 建信中证500指数增强`——税前 vs 税后**

| 来源 | 现金成分口径 |
| --- | --- |
| composite | 银行活期存款利率（**税后**） |
| fund_master | 商业银行活期存款利率（**税前**） |

**税前与税后是两个不同的利率**，差一个利息税率。必须确认以合同为准。

**`050002 博时裕富沪深300指数`——活期 vs 同业**

| 来源 | 现金成分口径 |
| --- | --- |
| composite | 银行**活期存款**利率（税后） |
| fund_master | 银行**同业存款**利率 |

**活期存款利率 ≠ 同业存款利率**，是两种完全不同的利率。必须确认以合同为准。
