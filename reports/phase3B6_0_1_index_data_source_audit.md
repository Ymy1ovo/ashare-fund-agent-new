## 2. 逐个数据源评估

### 2.1 中证指数有限公司（csindex.com.cn）

| 项 | 结论 |
| --- | --- |
| 接口 | `akshare.stock_zh_index_hist_csindex(symbol, start_date, end_date)` |
| 能否取日线 | ✅ |
| 能否取指数代码 | ✅ 直接传代码 |
| 完整历史 | ✅ 最早 2004-01-01（接口下限），实际覆盖到当日 |
| 含 OHLC | ✅ 开/高/低/收 + 成交量/成交额 |
| 复权口径 | 指数本身不需复权；另有全收益版本（如 000933） |
| 限流 | 中等，实测 1.5 秒间隔稳定；未触发限流 |
| 缺口 | 未见异常；接口按交易日返回 |
| 适合长期自动化 | ✅ **首选** |

实测样例（`000300` 沪深300，2026-11-23 调用）：

```
rows=5558, 2004-01-01 ~ 2026-11-20
列：日期 指数代码 指数中文全称 指数中文简称 指数英文全称 指数英文简称
    开盘 最高 最低 收盘 涨跌 涨跌幅 成交量 成交金额 样本数量 滚动市盈率
```
