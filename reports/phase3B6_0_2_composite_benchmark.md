## 3. 校验规则

| 规则 | 实现 |
| --- | --- |
| 缺成分 → 不可复现 | 成分列表为空即 `is_reproducible=0` |
| **单成分 → 不构成复合** | 只有 1 个成分时明确拒绝标可复现 |
| 缺权重 → 不可复现 | `weight IS NULL` 即不可复现，**不补造** |
| 成分无数据 → 不可复现 | `data_available=0` 即不可复现 |
| 指数未映射代码 → 不可复现 | 如实记为「未映射」 |
| 现金/固定加项无序列 → 不可复现 | 本阶段未接入 |
