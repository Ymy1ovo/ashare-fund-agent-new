## 0. 本轮修正：可复现性必须校验收益口径

### 0.1 修正前的问题

`add_component()` 只检查 `index_daily` 有没有记录，
`evaluate_composite()` 只看 `data_available`、权重、成分数、代码映射。

**完全没有检查 `index_master.return_basis`。**

后果：一个口径为 `unknown` 的指数，只要有历史点位，
就会被当成「可用于复合基准复现」——这是不允许的。

### 0.2 修正后的规则

| 检查项 | 规则 |
| --- | --- |
| 1. 指数代码存在 | 未映射代码 → 不可用 |
| 2. 有有效历史行情 | `index_daily` 无记录 → 不可用 |
| 3. **收益口径已核实** | `unknown` → 不可用 |
| 4. **口径必须合格** | 仅 `total_return` / `net_total_return` 通过 |
| 5. `price_return` | 禁止冒充全收益（不含分红） |
| 6. `unknown` | 禁止作为严格总收益基准 |
| 7. 债券/现金/固定加项 | 无收益序列 → 不可用 |
| 8. 缺历史权重 | 不可复现，**不补造** |

### 0.3 关键区分

> **「有历史行情数据」≠「有可用于总收益比较的历史序列」**

| 状态 | `data_available` | 能否用于总收益比较 |
| --- | --- | --- |
| 有行情 + 口径 total_return | 1 | 是 |
| 有行情 + 口径 net_total_return | 1 | 是（保留独立标识） |
| 有行情 + 口径 price_return | **0** | 否 |
| 有行情 + 口径 unknown | **0** | 否 |
| 无行情 | 0 | 否 |

校验在 `add_component()` 与 `evaluate_composite()` **两处**都执行。
