## 1. 分支语义

`app/backtest/broker.py`：

```python
if order.side == 'sell':
    net_proceeds = gross - fee
    if net_proceeds < 0 and portfolio.cash + net_proceeds < -1e-6:
        return self._terminate(order, 'sell_proceeds_below_fee', 'rejected')
```

触发条件（三者同时成立）：

1. 卖出方向
2. `gross - fee < 0` —— 成交金额小于总费用（含最低佣金 5 元）
3. `portfolio.cash + net_proceeds < 0` —— 现金不足以补足差额

**处理方式**：拒单（`rejected`），记原因 `sell_proceeds_below_fee`，
不产生成交记录、不扣费用、不改持仓、不制造负现金。
