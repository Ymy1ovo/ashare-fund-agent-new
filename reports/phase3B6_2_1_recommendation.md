## 1. 当前基准体系现状

### 1.1 类别分布（全部 vs 存续 vs 主口径）

| 类别 | 全部 | 存续 | 主口径（可信） |
| --- | ---: | ---: | ---: |
| `etf_feeder`（ETF联接基金） | 26 | 23 | 21 |
| `index_plain`（普通指数基金） | 25 | 14 | 13 |
| `active_equity`（主动权益基金） | 35 | 16 | 15 |
| `mixed_bond`（混合债券基金） | 17 | 11 | 11 |
| `money_market`（货币基金） | 8 | 7 | 6 |
| `pure_bond`（纯债基金） | 6 | 5 | 5 |
| `lof_offexchange`（LOF场外份额） | 3 | 3 | 2 |
| **合计** | **120** | **79** | **73** |

### 1.2 分类质量

| 置信度 | 数量 | 可否用于正式统计 |
| --- | ---: | --- |
| `primary_field`（高） | **73** | **可以** |
| `partial_field`（中） | 6 | 需注明 |
| `name_only_degraded`（低） | **41** | **不可以** |

**41 只清盘基金的 `fund_type_l1/l2` 全部为 `NULL`**，只能靠基金全名降级推断，
其类别标注**不得用于正式统计口径**。

### 1.3 幸存者偏差

> **幸存者偏差声明**：正式库含 41 只 terminated 基金，但全部无分类与基准文本（fund_type_l1 为 NULL）；存续基金 79 只。任何只基于存续基金的统计都存在幸存者偏差。

因此本报告的**权威统计以 `primary_scope`（73 只）为准**，全部 120 只的统计仅作参考。

## 2. 可用于研究的基金范围

### 2.1 可建研究评价基准：**37 只（主口径）**

条件：合同基准中含至少一个**已接入且有收益序列**的股票/综合指数。

| 可用指数 | 代码 | 覆盖行数 |
| --- | --- | ---: |
| 国债指数 | `000012` | 5,558 |
| 上证50 | `000016` | 5,559 |
| 沪深300 | `000300` | 5,558 |
| 中证500 | `000905` | 5,317 |
| 中证800 | `000906` | 5,317 |
| 中证红利 | `000922` | 5,317 |
| 内地消费 | `000942` | 5,317 |
| 中证白酒 | `399997` | 4,345 |
| 港股综合 | `930930` | 2,999 |
| 半导体 | `H30184` | 5,316 |

### 2.2 但研究基准 ≠ 合同基准

即使某基金有可用指数序列，其合同基准通常还包含：

| 缺口成分 | 主口径中受影响基金数 |
| --- | ---: |
| 含 `cash` 现金成分 | **48** |
| 含 `fixed_rate` 固定收益率 | **1** |
| 含 `bond_index` 债券指数 | **29** |
| 主口径基金总数 | **73** |

**只要合同基准里出现上述任一类，该基金就无法完整复现合同基准**，
即使其中的股票指数部分算得完全正确。

**成分类型分布（全部 120 只）**：

| 类型 | 出现次数 |
| --- | ---: |
| `equity_index` | 61 |
| `fixed_rate` | 2 |
| `cash` | 51 |
| `bond_index` | 37 |
| `unknown` | 3 |

## 3. 暂时不能建立基准的基金范围

### 3.1 无任何可用基准：**36 只（主口径）**

| 原因 | 说明 |
| --- | --- |
| 基准只含债券指数 | 中债/中证债券指数未接入，无法计算 |
| 基准只含存款利率 | 活期/定期/通知存款利率无历史序列 |
| 基准为纯固定收益率 | 折算规则未知 |
| 货币基金 | 需万份收益/七日年化独立口径 |

### 3.2 按类别的可建性

| 类别 | 主口径数量 | 可建研究基准 | 说明 |
| --- | ---: | ---: | --- |
| `etf_feeder`（ETF联接基金） | 21 | **11** | 同上，但目标ETF需另行处理 |
| `index_plain`（普通指数基金） | 13 | **9** | 跟踪指数已接入则可建 |
| `active_equity`（主动权益基金） | 15 | **13** | 需合同基准含已接入指数 |
| `mixed_bond`（混合债券基金） | 11 | **3** | 债券部分缺失，只能部分建 |
| `money_market`（货币基金） | 6 | **0** | 需独立口径，本轮不适用 |
| `pure_bond`（纯债基金） | 5 | **0** | 债券指数全缺，无法建 |
| `lof_offexchange`（LOF场外份额） | 2 | **1** | 同指数基金，但需场外份额净值 |

### 5.3 结论

**设计层面已具备进入 3B-6.2.2 的条件；数据层面不具备。**

| 维度 | 判断 |
| --- | --- |
| 分类体系设计 | **可进入下一阶段** |
| 正式基准接入 | **不可进入**——0 份 L1 证据、0 个口径确认 |

**建议 3B-6.2.2 定位为「L1 证据获取 + 指数口径确认」的专项，
而非「正式基准接入」。**
