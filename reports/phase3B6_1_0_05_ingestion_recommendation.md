## 2. 接入后的预期效果（诚实评估）

| 场景 | 可算超额收益的基金数 | 说明 |
| --- | ---: | --- |
| 当前 | **0** | 全阻断 |
| 仅接入指数全收益 | **0** | 复合基准仍缺成分 |
| 接入指数全收益 + 无风险利率 | **0** | 无风险利率不解决基准问题 |
| 再加债券指数 | **0** | 仍缺历史权重 |
| 再加历史权重 | **可能 >0** | 需逐条验证 |

**关键判断：单纯接入指数全收益，不会让任何基金的 `excess_return_status` 从 `not_available` 变成可用。**

原因：15 条复合基准中 **10 条含现金成分、5 条含债券成分、15 条全部只有当前权重**。
指数全收益只是其中一个必要条件。

| 只接入指数全收益就宣布超额收益可用 | 复合基准仍不可复现 |
