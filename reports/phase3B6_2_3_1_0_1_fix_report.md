## 5. NaN / Inf / 非法日期检查

### 5.1 修正前

```python
if isinstance(c, float) and (math.isnan(c) or math.isinf(c)):
```

**字符串 `"NaN"` 会绕过检查。**

### 5.2 修正后

`to_number()` 统一转换，覆盖：

| 输入 | 判定 |
| --- | --- |
| `None` | `null` |
| `float('nan')` / `float('inf')` | `nan` / `inf` |
| `"NaN"` `"nan"` `"+nan"` `"-nan"` | `nan_string` |
| `"Infinity"` `"inf"` `"+Inf"` | `inf_string` |
| `"-Infinity"` `"-inf"` | `neg_inf_string` |
| `""` | `empty_string` |
| `"abc"` | `non_numeric_string` |
| `True` / `False` | `bool` |
| 其他类型 | `unsupported_type` |

**同时对 `math.isfinite()` 做兜底检查。**

## 7. 附带发现：`2018-06-18` 的真相

原审计把 `2018-06-18` 列为「日历外日期」，导致 8 个股票序列
`continuity = has_issues`。

**本轮查明**：该日是**端午节**（A 股休市），但官方全收益序列仍返回一行，
特征是：

| 字段 | 值 |
| --- | --- |
| `tradingVol` | **0.0** |
| `changePct` | **0.01**（几乎不变） |
| `close` | 与前一日几乎相同（如 4613.77 → 4614.35） |

**这不是真实交易日行情，而是官方对全收益指数的休市日占位行。**

已实现 `_classify_outside_calendar()` 分类：

| 分类 | 含义 |
| --- | --- |
| `market_closed_placeholder` | 休市日占位（`tradingVol=0` 且 close≈前日） |
| `unexplained` | 无法解释，需进一步核查 |

**只有 `unexplained` 才影响连续性判定。**
