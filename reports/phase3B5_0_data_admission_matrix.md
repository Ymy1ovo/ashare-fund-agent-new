## 3. 准入原则

- unknown 不等于 false，NULL 不等于 0
- 接口能返回不等于证据等级高
- 已在净值中扣除的费率不得重复计提
- 平台日期不等于报告期末，报告期末不等于投资者已知
- 已知清盘清单不等于全量清盘名录

---

## 4. 证据等级定义

| 等级 | 定义 |
| --- | --- |
| **A** | 官方原始来源，可追溯原始公告或正式文件 |
| **A-** | 基金管理人正式公告原文，经第三方公告库转发，公告 ID 可回源 |
| **B** | 可信第三方转载或整理，但未逐条回源官方原文 |
| **C** | 第三方数据平台信息，尚未与合同或官方数据逐条核验 |
| **D** | 推断、代理或人工假设 |
| **unknown** | 无法确认 |
