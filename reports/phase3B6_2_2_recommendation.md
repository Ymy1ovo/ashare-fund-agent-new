### 1.1.1 置信度修正记录

**3B-6.2.2.1**：上一版把「有指数点位 + 全成分可算」直接评为 B 级，
没有要求映射关系本身有可靠证据，`004746` 因此被误评为 B。
修正后 `004746` → C，B 级归零，C 级 41 → 42。

**3B-6.2.2.1.1（本轮）**：修正 `compute_confidence()` 的关键缺口边界缺陷——
原逻辑只要映射证据为 L1/L2 就直接进入 B 分支，即使必要成分缺失也仍评 B。
本轮引入关键缺口判断后：

| 项 | 3B-6.2.2.1 | **本轮** | 原因 |
| --- | ---: | ---: | --- |
| A | 0 | **0** | 无 L1 官方合同文件 |
| B | 0 | **0** | 全部证据等级 `L3`，最高只能 C |
| C | 42 | **69** | +27：有候选指数成分（识别到指数名但代码未映射/债券指数未接入）但无可用序列 |
| D | 78 | **51** | −27：同上；D 仅剩无基准文本 42 只 + 仅利率/货币口径 9 只 |

**每一类变化的原因**：

| 变化 | 数量 | 具体原因 |
| --- | ---: | --- |
| D → C | 27 | 基准文本里**识别到了指数成分**（中证A500 8、上证科创50 4、创业板指 3、中债系列 8、中证全指/中证可转债等 4），只是代码未映射或债券指数未接入。属于「有合理候选映射 + 关键证据缺失」= C，不是「无候选映射」= D |
| 仍为 D | 42 | 无基准文本，无法建立任何候选关系 |
| 仍为 D | 8 | 货币基金，需万份收益/七日年化独立口径 |
| 仍为 D | 1 | 基准为「三年期银行定期存款利率(税后)+1.5%」等**纯利率成分**，无指数候选 |

**004746 仍为 C**（未受本轮修正影响）：仅有 L3 第三方资料，无法证明合同里写的确实是该指数。

### 1.2 C 级 69 只的构成

C 级定义是「存在合理候选映射，但关键证据缺失」。共同特征：

| 特征 | 后果 |
| --- | --- |
| 合同基准含可识别指数（含未映射代码、未接入债券指数） | 有候选关系 |
| **全部证据等级为 L3** | 无法确认映射身份 → 最高 C |
| 其中 42 只有已接入指数序列、27 只仅有指数名 | 收益序列不可确认 |

### 1.3 D 级 51 只的构成

| 组成 | 数量 | 原因 |
| --- | ---: | --- |
| 无基准文本 | 42 | 无法建立任何候选映射 |
| 货币基金（仅利率口径） | 8 | 需万份收益/七日年化独立口径 |
| 纯利率成分基准（存款利率+固定加点） | 1 | 无可识别指数候选 |

**D 级不因「收益口径 unknown」触发**——只由「无候选映射」或「分类降级」触发。

### 3.3 结论

**15 条复合基准全部不可完整复现**，与 3B-6.1.2 审计结论一致，本轮未放宽标准。

| 阻断项 | 说明 |

| 债券指数未接入 | 中债/中证债券指数无可用序列 |
| 现金利率无历史序列 | 活期/同业存款利率未接入 |
| 固定收益率折算规则未知 | 年化→期间折算方法未确认 |
| 历史权重全空 | `weight_effective_from` 全部为 NULL |
| 无 L1 合同 | 全部为 L3 第三方文本 |

**不得把复合基准简化为单一指数**——本轮全部保留原成分与权重。
