## 1. 基金类型分类（任务一）

### 1.1 两个独立维度，不得混为一谈

原报告只有「基金类型」一个模糊概念，把**投资类型**（股/债/混）
和**交易形式**（场内/场外/LOF）混在一起。本轮拆成两个独立字段。

#### 维度 A：产品结构 `product_structure`（交易形式）

| 枚举 | 含义 | 是否在场外结构范围 |
| --- | --- | --- |
| `ordinary_open_ended` | 普通开放式（场外，无场内交易代码） | ✅ |
| `etf_linked` | ETF 联接基金（场外申购，投资于目标 ETF） | ✅ |
| `etf` | 场内 ETF（交易所上市交易） | ❌ |
| `lof` | LOF（上市开放式，场内场外均可） | ✅ |
| `other` | 其他结构 | ❌ |
| `unknown` | 无法确认 | ❌ |

**注意**：「在场外结构范围」只表示这个产品形态理论上可以在场外申购，
**不表示支付宝当前在售，也不表示这些已清盘基金曾在支付宝上架**。

#### 维度 B：投资类型 `investment_type`

| 枚举 | 含义 |
| --- | --- |
| `money_market` | 货币市场 |
| `bond` | 债券 |
| `mixed` | 混合 |
| `equity` | 股票 |
| `index` | 指数（无法归入股/债/混时的兜底） |
| `other` | 其他 |
| `unknown` | 无法确认 |

### 1.2 判定依据（不得只凭代码前缀）

| 优先级 | 线索 | 说明 |
| ---: | --- | --- |
| 1 | 公告正文的基金全称 | 最可靠，来自基金公司正式文本 |
| 2 | 公告标题 | 次可靠 |
| 3 | 正文里的运作方式描述 | 辅助 |
| — | 代码前缀 | **只记录为 `prefix_hint`，不采信** |

代码前缀仅作线索记录，冲突时标记 `prefix_conflict`。
例：`501041` 以 501 开头（LOF 段）但公告原文未写 LOF，判为普通开放式。

## 3. 证据等级校准（任务二）

### 3.1 原报告的错误

原报告 3B-4.1.1 写「A 级证据 40 条」「43 条清盘全部 A 级」——**这是错的**。

错误根源：把「公告原文 PDF 能下载、内容完整可读」当成了 A 级的充分条件。
但证据分级看的是**发布渠道**，不是**可读性**。

### 3.2 新的分级标准

| 等级 | 标准 |
| --- | --- |
| **A** | 基金管理人官网 / 交易所官网 / 证监会电子披露平台的原始公告 |
| **B** | 第三方转载（东方财富等），原文完整可读、可追溯，但发布主体非官方 |
| **C** | 可靠第三方结构化摘要，无原文 |
| **D** | 无法确认来源 |

### 3.3 实测：43 条全部来自东方财富转载

| 公告链接域名 | 条数 | 能否给 A |
| --- | ---: | --- |
| `pdf.dfcfw.com`（东方财富） | 43 | ❌ **第三方转载** |
| `csrc.gov.cn` / `eid.csrc.gov.cn` | 0 | — |
| `sse.com.cn` / `szse.cn` | 0 | — |

**即使 PDF 内容是基金公司盖章的正式文本，发布渠道仍是东方财富转载，只能给 B。**

### 3.4 修正后证据分布

| 等级 | 数量 | 占比 |
| --- | ---: | ---: |
| **A** | 0 | 0.0% |
| **B** | 43 | 100.0% |
| **C** | 0 | 0.0% |
| **D** | 0 | 0.0% |
| **合计** | **43** | 100% |

> **43 条全部 B 级，A / C / D 均为 0。**

### 3.5 什么情况下能升 A？

| 条件 | 说明 |
| --- | --- |
| 回源到基金公司官网公告页 | 逐个打开基金公司官网对应公告 |
| 回源到交易所官网 | ETF/LOF 在上交所/深交所网站有原文 |
| 回源到证监会电子披露平台 | `eid.csrc.gov.cn`，但需人工检索 |

**本轮不做回源**：要求明确写「不重新采集公告」，且回源 43 条需人工逐条比对，
属于下一阶段工作。
