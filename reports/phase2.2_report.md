## 1. 问题与修复

### 原问题

`summarize_range()` 先 `dropna()` 再 `pct_change()`，把跨缺失日的收益压成普通单日收益，导致：

- 年化波动率错误；
- 夏普比率错误；
- 索提诺比率错误；
- 区间风险样本数与真实单日收益不一致。

### 修复

新增 `daily_return_series()`：

```python
close = adjusted_close.where(adjusted_close > 0)
returns = close.pct_change(fill_method=None)
```

- 在原始交易日索引上计算，缺失日保留 NaN。
- `summarize_range()` 和 `compute_risk()` 共用这个函数。
- 只删除缺口产生的 NaN，不删除真实单日收益。
- 有效单日收益少于 2 个时，波动率/夏普/索提诺返回空值。
- CAGR 继续使用阶段2.1的交易日索引位置差。
- 最大回撤继续使用有效价格观察序列，不填充、不把缺失价格当 0。
- 日表滚动风险指标使用 252 日窗口，区间摘要使用请求区间；两者共用真实单日收益和公式定义，窗口不同因此数值不必逐日相等。
